# Construction Materials category images

Filenames must be **lowercase** (Metro is case-sensitive):

| File | Category |
|------|----------|
| `cementBag.png` | Cement |
| `steel.png` | Steel |
| `bricks.png` | Bricks |
| `sand.png` | Sand |
| `aggregate.png` | Aggregate |
| `paint.png` | Paint |
| `tiles.png` | Tiles |
| `electrical.png` | Electrical |
| `plumbing.png` | Plumbing |
| `roofing.png` | Roofing |
| `hardware.png` | Hardware |
| `tools.png` | Tools |

After adding a new file, also add a `require(...)` line in `src/lib/materialsCategoryArt.ts`, then restart Metro.
